# 减脂训练计划

## 1. 饮食

### 每日目标

| 项目 | 目标 |
|---|---|
| 每日热量 | 1800–1900 kcal |
| 蛋白质 | 160–180 g |
| 吃饭次数 | 2 顿 |
| 加餐 | 不安排 |

### 第一顿

| 食物 | 重量 |
|---|---:|
| 鸡胸肉 / 瘦牛肉 | 250 g（生重） |
| 熟米饭 | 200 g |
| 蔬菜 | 300 g |
| 水果 | 1 个 |

### 第二顿

| 食物 | 重量 |
|---|---:|
| 鸡胸肉 / 瘦牛肉 | 250 g（生重） |
| 熟米饭 | 200 g |
| 蔬菜 | 300 g |
| 无糖高蛋白酸奶 | 300 g |
| 鸡蛋 | 2 个 |

### 其他要求

- 烹饪油：10–15 g / 天
- 肉类重量均按生重计算
- 米饭重量按熟重计算
- 可以喝：水、无糖茶、黑咖啡、零糖饮料
- 两顿之间不吃零食
- 每天步数：8000–10000 步，尽量接近 10000 步

### 聚餐

每周最多 1 次。

如果晚上聚餐：

- 白天吃一顿高蛋白、低热量饮食
- 白天控制在约 600–750 kcal
- 晚上正常聚餐，尽量控制总量
- 聚餐日全天尽量 ≤ 2500 kcal
- 优先吃肉、鱼虾、蔬菜
- 少吃油炸、甜点、肥肉
- 尽量少喝酒
- 第二天直接恢复正常饮食
- 不额外断食
- 不额外补有氧

## 2. 训练

### 每周安排

- 力量训练：每周 5 次，最少 3 次（A、B、C）
- 每天步数：8000–10000 步
- 不再单独安排长时间有氧，见下方「有氧（可选）」
- 每次训练约 60–90 分钟（含热身）

每周按顺序练：

**A → B → C → D → E**

不需要绑定星期几。

某周只能练 3–4 次时，优先完成 A、B、C，D、E 能做几次做几次，下周照常从 A 开始。

| 训练 | 重点 |
|---|---|
| A | 全身：股四头 + 背 + 胸 |
| B | 全身：臀腿后侧 + 背 + 胸 |
| C | 全身：背 + 腿 + 胸 |
| D | 下肢 + 核心 |
| E | 背部体态 + 肩臂 + 核心 |

排法示例（不强制）：

| 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
|---|---|---|---|---|---|---|
| A | B | C | 休 | D | E | 休 |

C 和 D 都会练到股四头，尽量不要连着练。

---

### 热身

每次训练前约 5 分钟，针对久坐：

| 动作 | 次数 |
|---|---:|
| 猫牛式 | 8 次 |
| 半跪髋屈肌拉伸 | 每侧 30 秒 |
| 胸椎开书式 | 每侧 8 次 |
| 弹力带拉开（没有弹力带就用轻重量面拉） | 15 次 |
| 臀桥 | 12 次 |

每次训练的第一个动作，先做 1–2 组轻重量热身组，不计入正式组数。

### 有氧（可选）

不再单独安排 30–60 分钟的有氧。

每天 8000–10000 步就是主要的有氧，尽量在日常里走完：

- 饭后走 10–15 分钟
- 每坐 1 小时，起来走 2–3 分钟

力量训练后的坡走改为可选，只在以下情况做：

- 当天步数不到 8000
- 两周减重不达标（见「每两周调整一次」）

| 有氧 | 设置 |
|---|---|
| 跑步机坡走 | 10–15 分钟 |
| 坡度 | 6–10 |
| 速度 | 4.5–5.2 km/h |

坡走时不要扶扶手。

---

### 组间休息和省时

| 动作类型 | 组间休息 |
|---|---|
| 复合动作：腿举、深蹲、罗马尼亚硬拉、划船、下拉、卧推 | 约 2 分钟 |
| 孤立动作：侧平举、面拉、腿弯举、腿屈伸等 | 60–90 秒 |
| 超级组 | 两个动作连着做完算一轮，一轮后休息 60–90 秒 |

用计时器控制休息时间。

---

### 力量训练标准

每组保持：

**RIR 1–2**

即每组结束时，感觉最多还能标准完成 1–2 次。

不需要每组做到完全力竭。

补充：

- 深蹲、罗马尼亚硬拉保持 **RIR 2**
- 新加的动作（D 训练的腿部动作、所有核心动作），前 2 周每个只做 2 组、用轻重量，第 3 周开始按表格组数做
- 核心动作也按 RIR 1–2 来做，动作一变形就停；太轻松或太难时，按下方「核心进阶」调整

### 加重量规则

假设动作要求 8–12 次：

| 本次表现 | 下次训练 |
|---|---|
| 10 / 9 / 8 | 重量不变 |
| 12 / 11 / 10 | 重量不变 |
| 12 / 12 / 12 | 增加重量 |

加重建议：

- 上肢：增加 1–2.5 kg
- 下肢：增加约 2.5–5 kg
- 辅助引体：如果可以稳定完成 10 / 10 / 10，减少辅助重量

### 核心进阶

每组都能用标准动作做满次数或时间上限，下次升一级；做不到下限，退回一级。

| 训练 | 当前动作 | 太难或没器械时 | 太轻松时 |
|---|---|---|---|
| A | 杠铃滚轮（跪姿） | 瑞士球滚动 / 负重死虫（双手举 5–10 kg 哑铃，每侧 10–12 次） | 往前滚得更远 |
| B | 绳索卷腹 | 减轻重量 | 按加重量规则加重量 |
| C | RKC 平板支撑 | 普通平板支撑 30–60 秒 | 手肘往前放远一点 |
| D | 悬垂举腿（屈膝） | 罗马椅举腿 / 反向卷腹 | 直腿悬垂举腿 |
| E | 负重侧平板 | 不负重 | 换更重的杠铃片 |

动作要点：

- 杠铃滚轮：杠铃两边各装一片直径大的圆形杠铃片（比如 20 kg 片；多边形的片滚不动），跪在垫子上双手握杠往前滚；腰快要塌下去之前就收回来；全程夹臀、收腹
- RKC 平板支撑：手肘撑地，全身用最大力绷紧：夹臀、收腹，手肘往脚的方向用力拉（身体不动）。做对了 20 秒就很吃力
- 负重侧平板：杠铃片放在上侧髋部，用上面的手扶住；身体从头到脚保持一条直线

### 替代动作

器械被占或者没有时使用：

| 原动作 | 可替换为 |
|---|---|
| 坐姿腿举 | 哈克深蹲 / 高脚杯深蹲 |
| 深蹲（D 训练） | 坐姿腿举 |
| 胸托划船 | 单臂哑铃划船 |
| 45° 山羊挺身 | 罗马尼亚硬拉 |
| 悬垂举腿 | 罗马椅举腿 / 反向卷腹 |

### 每两周调整一次

| 两周减重情况 | 调整 |
|---|---|
| 0.5–0.9 kg / 周 | 不调整 |
| 连续两周 < 0.4 kg / 周 | 每天少约 100–150 kcal，或增加 1500–2000 步，或每次训练后加 10–15 分钟坡走 |
| > 1 kg / 周且训练状态明显下降 | 每天增加 150–200 kcal |
